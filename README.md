Автоматизация тестирования (UI и API)


В рамках данной работы реализован проект по автоматизации тестирования веб-приложения. В проекте автоматизированы пользовательские интерфейсные тесты и API-тесты на основе финальной работы по ручному тестированию. Основная цель проекта заключается в закреплении навыков автоматизации, создании переиспользуемой структуры тестового проекта и обеспечении удобного запуска тестов в разных режимах.

В проекте реализованы UI-тесты, которые проверяют основные пользовательские сценарии, такие как открытие главной страницы, выполнение поиска, проверка корректности перехода по страницам и отображения данных. Также реализованы API-тесты, которые проверяют корректность работы серверной части приложения, включая статус ответа, структуру данных, обработку некорректных запросов и получение данных.

Структура проекта организована следующим образом:

project/

tests/ — содержит UI- и API-тесты (test_ui.py, test_api.py)

pages/ — содержит Page Object классы для работы с UI

api/ — содержит клиент для работы с API

config/ — содержит настройки проекта и тестовые данные

conftest.py — содержит фикстуры pytest

pytest.ini — содержит конфигурацию запуска тестов

requirements.txt — содержит список зависимостей

README.md — описание проекта

Для установки зависимостей необходимо выполнить команду:

pip install -r requirements.txt

Для запуска всех тестов используется команда:

pytest

Для запуска только UI-тестов используется команда:

pytest -m ui

Для запуска только API-тестов используется команда:

pytest -m api

Для генерации отчёта Allure используется команда:

pytest --alluredir=allure-results

Для просмотра отчёта Allure используется команда:

allure serve allure-results
